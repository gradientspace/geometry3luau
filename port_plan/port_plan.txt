geometry3luau - PORT PLAN for the rest of geometry3Sharp
=========================================================
Source: gradientspace/geometry3Sharp, branch dotnet8 (commit 4664ac3, 2026-01-05): 338 .cs files.
About 130 of the files are already ported (listed at the end). Everything else is listed below.

HOW TO READ AN ENTRY
  [rec]  LEAF  TypeName(s)                      source file, C# line count
         Description.
         used by: ...   needs: ...

  [rec]   My recommendation. port = worth porting; maybe = useful in some cases; skip = probably not
          worth it on Roblox; alias = trivial, just an alias or a Luau idiom.
  LEAF    Nothing else in geometry3Sharp references this type (only its own file does). Leaf types are
          usually safe to drop without affecting anything else.
  used by Other geometry3Sharp files that reference the type. A name ending in * is already ported (so
          porting the type may unlock a missing feature there). "-" means none, i.e. LEAF.
  needs   Not-yet-ported files this one depends on (named by their main type). Deleting one of those
          means deleting this too, or reworking it. Already-ported dependencies are not listed.
          Both lists are computed per source file and name a file by its type when it has one type,
          otherwise by its file name (e.g. "BoxGenerators"). Entries that share a file show the same
          needs.

ORDERING
  Groups are ordered by the order I suggest porting them in, judged by value for Roblox modelling and
  by what each group depends on. Within a group, entries are roughly in dependency order (things
  higher up are needed by things lower down). Float types (Vector3f, Frame3f, ...) are already
  aliases of the double types (see PORTING.md), so they are not listed.
